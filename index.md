Assignment 7.4 — Modern Landing Page Header

Aim

To create a modern, responsive landing page with a navigation header, hero section, image, call-to-action buttons, and footer using CSS Flexbox.

Flexbox Properties Used

- "display: flex" — Arranges elements in a flexible layout.
- "justify-content: space-between" — Distributes items with space between them.
- "align-items: center" — Aligns items along the cross axis.
- "flex-direction: column" — Stacks hero content vertically on smaller screens.
- "flex-wrap: wrap" — Allows items to wrap when space is limited.
- "flex: 1 1 450px" — Demonstrates flexible sizing of the hero content.
- "gap" — Adds spacing between elements.

Features

- Logo, navigation links, and Get Started button.
- Hero heading, description, and call-to-action buttons.
- Workspace image displayed beside the hero text.
- Sticky navigation header.
- Features section with three cards.
- Footer with a Back to Top link.
- Responsive layout for desktop, tablet, and mobile screens.

Files Included

- "index.html" — Structure of the landing page.
- "style.css" — Styling, Flexbox layout, and responsive media queries.
